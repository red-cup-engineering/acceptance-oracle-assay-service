# Acceptance Oracle Assay

This settlement performs one operation: it mechanically assays whether a
bounded acceptance-oracle carrier binds its declared source and oracle artifact
measures, structured vector IDs, and an already-produced red execution witness.
It does not review implementation candidates, author tests, execute tests,
dispatch models, mutate territory, or accept usefulness.

Its receipt claims only those mechanical bindings. A red witness remains the
evidence of red execution; an identifier or marker is not treated as proof of
behavior beyond that witness.
